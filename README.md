# TonBanAPP 统班应用

TonBanAPP 是一个面向资助服务中心助理值班统计的 Windows 桌面工具。它把“维护助理总名单、配置特殊规则、生成每周 Excel、汇总每月 Word、处理加班补录和罚班记录”连成一套固定流程，减少人工数名单、抄数据、结转上月结果和调整 Word 表格格式的重复工作。

如果你是第一次接手统班工作，建议先看根目录的 [统班工作新手操作指南.md](./统班工作新手操作指南.md)。README 主要用于说明项目能力、运行方式、文件格式和开发维护信息。

## 核心能力

- 总名单管理：支持导入 Excel 通讯录，自动识别姓名、部门、专业、年级，并按最靠前年级自动标记毕业季助理；也兼容导入旧版 Word 名单。
- 名单编辑：可新增、删除、重命名助理，修改部门、专业、年级，并直接标记“毕业季”和“长期请假”。
- 规则配置：支持毕业季助理“正常值班 / 少值班 / 无需值班”三档规则，以及长期请假助理规则。
- 周统计 Excel：优先读取排班 PDF（兼容排班 Word），实际名单仍使用 Word；结合放假核减与特殊规则生成周统计 Excel。
- 期末周统计：读取一份包含两个周次区块的排班 PDF 和两份实际值班 Word，将两周期末周合并为一个统计周期并生成一份 Excel。
- 扫描 PDF：内置离线 Tesseract OCR，支持没有文字层的扫描排班表；无需另行安装 OCR 软件。
- 月统计 Word：汇总 1 到 4 份周统计 Excel，可结转上月 Word 的多值班次和缺班数量。
- 月度调整：支持加班补录和罚班记录的手动维护、Word 导入、Word 导出。
- 生成前预览：周统计和月统计生成前都能预览并修正关键数据。
- 本地配置：总名单、规则、主题和输出目录保存在 `data/config.json`。
- 打包交付：提供 PyInstaller 单文件打包配置。

## 业务流程

```text
导入/维护总名单
    ↓
配置毕业季、长期请假等特殊规则
    ↓
每周选择排班 PDF/Word + 实际 Word
    ↓
生成并核对周统计 Excel
    ↓
每月汇总 1-4 份周统计 Excel
    ↓
按需结转上月 Word、添加加班补录和罚班记录
    ↓
生成月统计 Word
```

## 页面说明

### 总名单

用于建立统班工作的人员基准。所有后续统计都以当前总名单为准。

主要操作：

- `导入名单`：选择 `.xlsx` 通讯录或 `.docx` 名单。
- `编辑`：新增、删除、重命名助理，维护部门、专业、年级和规则标记。
- `搜索姓名`：只影响当前显示，不会修改保存数据。
- `特殊识别`：一键删除已标记的毕业季助理。该操作不可逆，使用前需确认。

Excel 通讯录解析规则：

- 表头中需要能识别到“姓名”和“专业年级”，或“姓名”“专业”“年级”。
- “部门”列可以是合并单元格式的分组，程序会向下沿用上一条部门。
- “专业年级”可写成 `新闻22级`、`24级法学`、`材料 24级`、`AIA22级` 等形式。
- 系统会取届号最小的一批人作为毕业季助理。

Word 名单解析规则：

- 读取正文段落和表格单元格。
- 识别 2 到 4 个连续中文字符作为姓名。
- 支持姓名内部全角空格，例如 `张　爽` 会识别为 `张爽`。
- 普通空格用于分隔姓名，不会把 `张三 李四` 合并成一个人。

### 规则配置

用于维护影响周统计“应值班次”的特殊规则。

毕业季特殊逻辑：

- `正常值班`：不改变排班 Word 统计出的应值班次。
- `少值班`：毕业季助理本周应值班次固定为 1；如果被安排在放假日，仍会核减，最低为 0。
- `无需值班`：毕业季助理本周应值班次固定为 0。

长期请假规则：

- 被标记为长期请假的助理，在周统计中应值班次视作 2。
- 如果同一人同时是毕业季助理，且毕业季模式不是“正常值班”，毕业季规则优先。

### 周统计

用于生成单周值班统计 Excel。

需要准备：

- 排班 PDF/Word：用于计算“应值班次”，优先使用 PDF；PDF 可为文本表格或扫描件。
- 实际 Word：用于计算“实际班次”。
- 年份、学期、周次。
- 本周周一到周五是否有放假日。

输出列固定为：

```text
姓名 / 应值班次 / 实际班次 / 缺班 / 备注
```

计算口径：

```text
应值班次 = 排班 PDF/Word 中出现次数，经放假核减、长期请假、毕业季规则调整
实际班次 = 实际 Word 中出现次数
缺班 = max(0, 应值班次 - 实际班次)
```

注意：

- 放假核减只支持周一到周五。
- 星期标题必须单独成行，例如 `周一`、`星期一`、`礼拜一`、`周1`。
- 文本型 PDF 会直接读取星期列和姓名；扫描 PDF 会自动调用内置 OCR。OCR 结果受扫描清晰度影响，生成前请重点核对未知姓名提醒和预览中的应值班次。
- 周统计阶段不处理加班补录；加班补录只在月统计中体现。
- 生成前可在预览窗口编辑“应值班次”“实际班次”“备注”。
- 普通周统计固定按普通倍率计算；期末考试周请使用侧边栏独立的“期末周统计”。
- 生成前会做合理性校验（只提醒、不阻断，可选择“仍要生成”，预览中高亮异常行）：单助理本周应值班次大于 2；排班/实际 Word 中出现不在总名单的姓名；某份 Word 未识别到任何总名单内姓名（疑似选错文件）。
- 防打错字提醒：若排班 / 值班表里出现不在总名单、但与某位助理姓名相似的名字，会单独弹出“疑似打错字提醒”。判定结合**字符编辑距离**（覆盖替换 / 漏字 / 多字）与**拼音相似度**（忽略声调、多音字任一读音匹配、模糊音如 zh/z、an/ang、in/ing、l/n），并分两段呈现：
  - 疑似打错字：整名读音一致但用字不同（如“张爽”→“张霜”），或差一个字且读音相近 / 漏字多字；
  - 形近待确认：差一个字但读音不同（为避免遗漏，两字姓名同样列入；同姓不同名也会出现在这一段，扫一眼确认即可）。
  - 选好总名单和两份 Word 后，右侧“生成前检查”面板的“姓名拼写检查”会实时显示疑似数量（按疑似 / 形近分别计数），明细在点“生成 Excel”时的弹窗里查看。

### 期末周统计

用于将两个期末考试周作为一个统计周期处理。需要准备一份包含两个周次区块的排班 PDF，以及按 PDF 区块顺序对应的两份实际值班 Word。

- 系统内部按版面顺序称为“期末周1”和“期末周2”，不代表固定周数；实际周数可核对和修正，但不进入输出文件名。
- PDF 两个区块中的姓名先合并去重；每个唯一姓名整个期末周期应值 2。
- 两份实际 Word 合并但不去重，每次姓名出现计 2 次实际班次。
- 长期请假整个期末周期应值固定为 2，毕业季规则继续优先。
- 期末周统计不提供或执行放假核减。
- 毕业季处于“少值班”且存在生效人员时会阻止生成，需改为“正常值班”或“无需值班”。
- 默认预览一张合并表，确认后只生成一份 Excel。

默认文件名：

```text
{年份}{春季/秋季}学期期末周助理值班统计.xlsx
```

### 月统计

用于汇总一个月的周统计 Excel，并生成月度 Word。

需要准备：

- 1 到 4 份周统计 Excel。
- 上月月统计 Word，可选。首次使用或无上月数据时留空。
- 年份、学期、起始周、结束周。
- 本月加班补录，可选。
- 本月罚班记录，可选。

输出列固定为：

```text
序号 / 姓名 / 总计班次 / 应值班次 / 多值班次 / 缺班数量
```

计算口径：

```text
总计班次 = 本月周 Excel 实际班次合计 + 上月多值班次 + 本月加班补录
应值班次 = 本月周 Excel 应值班次合计 + 上月缺班数量 + 本月罚班记录
多值班次 = 总计班次 - 应值班次
缺班数量 = 应值班次 - 总计班次
```

展示规则：

- 多值班次或缺班数量小于等于 0 时，Word 单元格留空并画左上到右下斜线。
- 大于 0 时显示对应数字。
- 月统计只统计当前总名单内人员；已经离开总名单的人不会进入新报表。
- 新加入总名单的人，上月结转按 0 处理。
- 生成前会做合理性校验（只提醒、不阻断，可选择“仍要生成”，预览中高亮异常行，均排除毕业季助理）：仅当选满 4 份周 Excel 时，非毕业季助理的“各周应值合计”（不含罚班和上月结转）应在 4 到 8 之间；某人在所选周里应值与实际均为 0（可能被遗漏排班）。

默认文件名：

```text
{年份}{春季/秋季}学期{起始周}-{结束周}周助理值班统计.docx
```

### 加班补录和罚班记录

两者都在“月统计”页面维护。

加班补录：

- 用于记录本月额外完成的值班。
- 计入月统计的“总计班次”。
- 支持手动添加、清空、导入 Word、导出 Word。
- 导入 Word 至少包含表头 `姓名 / 加班班次`。

罚班记录：

- 用于记录本月额外应承担的值班次数。
- 计入月统计的“应值班次”。
- 支持手动添加、清空、导入 Word、导出 Word。
- 导入 Word 至少包含表头 `姓名 / 罚班次数`。

导入规则：

- 姓名必须在当前总名单中。
- 次数必须为正整数。
- 同一人多行会累加。
- 导入会覆盖当前界面中对应类型的已有记录。

根目录提供了两份空白模板：

- `加班补录空白模板.docx`
- `罚班记录空白模板.docx`

## 文件格式约定

### 周排班 PDF / Word 与实际 Word

排班文件优先支持 `.pdf`，并兼容 `.docx`。实际名单仍使用 `.docx`。

- 文本型 PDF：直接按表格中的周一至周五列解析。
- 扫描型 PDF：先检测表格网格，再使用随应用打包的 Tesseract 简体中文模型离线识别。
- 多页 PDF：逐页合并，同一姓名重复出现会继续表示多次排班。
- 扫描件若存在模糊、倾斜或特殊字体，可能产生未知姓名提醒；可在生成前预览中人工修正班次。

支持的星期标题：

- 周一、星期一、礼拜一、周1
- 周二、星期二、礼拜二、周2
- 周三、星期三、礼拜三、周3
- 周四、星期四、礼拜四、周4
- 周五、星期五、礼拜五、周5
- 周六、星期六、礼拜六、周6
- 周日、星期日、星期天、礼拜日、礼拜天、周7

约定：

- 星期标题必须单独成行。
- 标题后、下一个星期标题前出现的总名单内姓名，会计入当前星期。
- 同一姓名重复出现会保留，用于表示同一人多次排班或实际值班。
- 不在总名单中的姓名会被忽略。

### 周统计 Excel

月统计读取周 Excel 时，至少需要包含：

```text
姓名 / 应值班次 / 实际班次
```

### 上月月统计 Word

上月 Word 至少需要有一个表格，并包含：

```text
姓名 / 多值班次 / 缺班数量
```

解析规则：

- 空单元格按 0 处理。
- 非数字文本按 0 处理。
- 带左上到右下斜线的单元格按 0 处理。
- 负数按 0 处理。

## 运行环境

- Windows 桌面环境优先。
- Python 3.10+。
- 图形界面使用 `customtkinter`。

安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

启动应用：

```powershell
python main.py
```

也可以双击：

```text
start_tonban.bat
```

## 主要源码说明

- `src/modules/data_manager.py`：读写 `data/config.json`，维护名单、规则、主题、输出目录。
- `src/modules/contact_parser.py`：解析 Excel 通讯录，识别姓名、部门、专业、年级和毕业季助理。
- `src/modules/word_parser.py`：解析 Word 名单、周排班/实际 Word、上月月统计 Word。
- `src/modules/schedule_parser.py`：按扩展名统一分派 PDF/Word 排班文件。
- `src/modules/pdf_schedule_parser.py`：解析文本型 PDF，并对扫描 PDF 执行表格检测和 OCR。
- `src/modules/final_weeks_parser.py`：按版面顺序拆分双周期末排班 PDF，并识别实际周数。
- `src/modules/final_weeks_service.py`：提供期末周合并统计和单文件输出，并保留停用的双文件流程。
- `src/modules/ocr_runtime.py`：定位和调用开发环境或 PyInstaller 内置的 Tesseract。
- `src/modules/excel_generator.py`：计算并生成周统计 Excel，也负责聚合周 Excel。
- `src/modules/word_generator.py`：计算月统计数据并生成固定版式 Word。
- `src/modules/overtime_word.py`：导入/导出加班补录和罚班记录 Word。
- `src/ui/main_ui.py`：主窗口、侧边栏、顶部状态、设置弹窗和页面切换。
- `src/ui/name_list_tab.py`：总名单导入、搜索、编辑和特殊识别。
- `src/ui/rules_tab.py`：毕业季和长期请假规则配置。
- `src/ui/weekly_tab.py`：周统计输入、预览和 Excel 生成。
- `src/ui/final_weeks_tab.py`：双周期末排班、两份实际 Word、默认单表预览和单 Excel 生成。
- `src/ui/monthly_tab.py`：月统计输入、调整记录、预览和 Word 生成。


```text
tonban_exe/TonBanAPP.exe
```

发布注意：

## 常见问题

### 导入名单后人数不对

先确认文件类型。如果是 Excel 通讯录，检查是否有“姓名”和“专业年级”相关表头。如果是 Word 名单，当前姓名识别规则是 2 到 4 个中文字符，1 字名、5 字及以上姓名、带间隔点或英文字母的姓名可能无法识别。

### 周统计没有识别某一天

星期标题必须单独成行。`周一` 单独一行可以识别，`周一 张三 李四` 不会被当作有效星期标题。

如果使用扫描 PDF，请确认表格边框完整、页面没有明显倾斜且姓名清晰。程序会先尝试识别六列表格网格；无法定位星期列时会阻止生成并给出错误提示。

### 生成时报文件无法写入

目标 Excel 或 Word 可能正在被打开。关闭对应文件后重新生成。

### 月统计 Word 生成失败

优先检查：

- 是否已导入总名单。
- 是否选择了 1 到 4 份周统计 Excel。
- 周 Excel 是否包含 `姓名 / 应值班次 / 实际班次`。
- 上月 Word 是否包含 `姓名 / 多值班次 / 缺班数量`。
- 年份、学期、起始周、结束周是否合法。
