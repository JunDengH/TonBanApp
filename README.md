# 统班应用 TonBanAPP

统班应用是一个面向值班班统计场景的 Python 桌面工具。可以拓展到小规模公司考勤使用。它把“总名单维护、每周值班统计、月末 Word 报表汇总”串成一套流程，减少人工清点 Word 名单、核减假期、结转上月多值/缺班和排版的重复工作。

当前项目已经实现图形界面、Word 名单解析、周统计 Excel 生成、月统计 Word 生成、大四助理规则、放假核减、月统计加班补录、上月 Word 结转，以及较完整的自动化测试。

## 主要能力

- 总名单管理：从 `.docx` 导入助理总名单，自动提取中文姓名、去重并持久化到 `data/config.json`。
- 大四助理规则：可从总名单中选择大四助理，并用总开关控制周统计时是否将其应值班次固定为 1 次。
- 周统计 Excel：分别选择“排班名单 Word”和“实际名单 Word”，生成包含应值班次、实际班次、缺班和备注的 Excel。
- 放假核减：可勾选周一到周五的放假日期，自动核减当天排班人员的应值班次。
- 月统计 Word：汇总 1 到 4 份周统计 Excel，按代码内置版式生成正式月度 Word 报表。
- 跨月结转：可读取上月月度 Word 中的多值班次和缺班数量，计入本月统计。
- 月统计加班补录：在月统计阶段手动给指定人员追加班次，并计入最终总计班次。
- 样式复刻：月统计 Word 内置 5-8 周成品文件的页面、表格、自动编号和斜线占位格式，不依赖外部模板。

## 使用流程

### 1. 导入总名单

打开“总名单管理”，点击“导入 / 更新总名单”，选择总名单 Word。

解析规则：

- 支持正文段落和表格单元格。
- 识别 2 到 4 个连续中文字符作为姓名。
- 支持姓名中的全角空格，例如 `张　爽` 会识别为 `张爽`。
- 普通空格用于分隔姓名，不会把 `张三 李四` 拼成一个名字。
- 导入后名单会去重、保持首次出现顺序，并写入 `data/config.json`。

### 2. 配置大四助理规则

打开“大四助理规则”，从当前总名单中勾选大四助理并保存。

规则开启后：

- 被选中的大四助理周统计应值班次固定为 1 次。
- 放假核减仍优先生效，最低扣到 0。
- 规则开关和名单都会持久化。
- 更新总名单后，不在新总名单中的大四助理会自动移除。

### 3. 生成周统计 Excel

打开“周统计生成”，选择两个 Word 文件：

- 排班名单：用于计算“应值班次”。
- 实际名单：用于计算“实际班次”。

可按需勾选本周放假日期，然后点击“生成周统计Excel”。默认建议输出到 `output/`，文件名形如：

```text
周统计_YYYYMMDD_HHMMSS.xlsx
```

周统计输出列固定为：

```text
姓名 / 应值班次 / 实际班次 / 缺班 / 备注
```

核心口径：

- 应值班次 = 该人员在排班 Word 中出现的次数。
- 实际班次 = 该人员在实际 Word 中出现的次数。
- 缺班 = `max(0, 应值班次 - 实际班次)`。
- 放假核减只影响放假当天被排班的人员，按当天排班次数扣减。
- 周统计阶段不做加班补录。

### 4. 生成月统计 Word

打开“月统计Word生成”，选择 1 到 4 份周统计 Excel。首次使用或没有上月数据时，“上月Word”可以留空。

可配置：

- 年份
- 春季 / 秋季
- 起始周
- 结束周
- 月统计加班补录

标题会被强制拼装为：

```text
{年份}{春季/秋季}学期{起始周}-{结束周}周助理值班统计
```

默认建议输出到 `output/`，文件名形如：

```text
月度统计_YYYYMMDD_HHMMSS.docx
```

月统计输出列固定为：

```text
序号 / 姓名 / 总计班次 / 应值班次 / 多值班次 / 缺班数量
```

核心口径：

```text
总计班次 = 本月周 Excel 实际班次合计 + 上月多值班次 + 本月加班补录
应值班次 = 本月周 Excel 应值班次合计 + 上月缺班数量
多值班次 = 总计班次 - 应值班次
缺班数量 = 应值班次 - 总计班次
```

展示规则：

- 多值班次或缺班数量小于等于 0 时，单元格留空并画左上到右下斜线。
- 大于 0 时显示对应数字。
- 月统计以当前总名单为唯一人员基准；离开总名单的人不进入新报表，新加入人员的上月结转按 0 处理。

## Word 与 Excel 格式约定

### 周排班 / 实际名单 Word

星期标题必须单独成行。支持：

- 周一、星期一、礼拜一、周1
- 周二、星期二、礼拜二、周2
- 周三、星期三、礼拜三、周3
- 周四、星期四、礼拜四、周4
- 周五、星期五、礼拜五、周5
- 周六、星期六、礼拜六、周6
- 周日、星期日、星期天、礼拜日、礼拜天、周7

标题之后、下一个星期标题之前出现的总名单内姓名，会归入当前星期。重复姓名会保留，用于表示同一人多次排班或值班。

### 周统计 Excel

月统计读取周 Excel 时要求至少包含：

```text
姓名 / 应值班次 / 实际班次
```

不在当前总名单中的人员会被忽略。

### 上月月度 Word

上月 Word 必须包含一个表格，且表头至少包含：

```text
姓名 / 多值班次 / 缺班数量
```

解析时，空单元格、非数字文本和带左上到右下斜线的单元格都会按 0 处理。

### 月度 Word 版式

月统计 Word 不再依赖外部模板文件。生成器会直接从空白文档创建固定格式表格，版式规格已固化在代码中：

- 第 1 个表格是目标表格。
- 第 0 行是标题行。
- 第 1 行是表头行。
- 列顺序为：序号、姓名、总计班次、应值班次、多值班次、缺班数量。
- 序号列使用 Word 自动编号。
- 多值班次/缺班数量小于等于 0 时使用左上到右下斜线占位。

## 常见问题

### 导入总名单后人数不对

当前姓名识别规则是 2 到 4 个中文字符。1 字名、5 字及以上姓名、带间隔点或英文字母的姓名可能不会被识别，需要调整解析规则后再导入。

### 周统计没有识别某一天

星期标题必须单独成行。例如 `周一` 单独一行可以识别，`周一 张三 李四` 不会被当作有效星期标题。

### Excel 或 Word 无法写入

目标文件可能正在被 Excel 或 Word 打开。关闭对应文件后重新生成即可。

### 月统计 Word 生成失败

优先检查：

- 是否已导入总名单。
- 是否至少选择了一份周统计 Excel。
- 周 Excel 是否包含 `姓名 / 应值班次 / 实际班次`。
- 上月 Word 是否包含 `姓名 / 多值班次 / 缺班数量` 表头。
