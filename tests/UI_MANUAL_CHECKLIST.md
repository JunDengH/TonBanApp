# UI 手工测试清单

## Tab 1：基础设置
- [ ] 首次打开程序，人数显示为 0
- [ ] 点击"导入总名单"，选一个正常Word → 人数更新、名单展示
- [ ] 关闭程序再打开 → 名单仍然存在（JSON持久化）
- [ ] 再次导入新Word → 名单被替换
- [ ] 导入一个空/格式错的Word → 弹出友好的错误提示，程序不崩溃

## Tab 2：周统计生成
- [ ] 未导入总名单就点"生成" → 弹出警告
- [ ] 不选文件就点"生成" → 弹出警告
- [ ] 正常生成：不勾选放假 → Excel的应值班次等于排班Word中该姓名出现次数
- [ ] 勾选"周三" → 周三值班的人应值班次-1
- [ ] Excel已在Excel里打开 → 弹出"请关闭文件"而非崩溃
- [ ] 生成后缺班多的人排在最上方

## Tab 3：月统计Word生成（需求3）
### 基础
- [ ] 未导入总名单就点"生成" → 弹出警告
- [ ] 不选任何周Excel就点"生成" → 弹出警告
- [ ] 只选1~3个文件也能生成（代码允许 <4 份）
- [ ] 上月Word选了一个不存在的路径 → 弹警告不崩溃
- [ ] 默认保存文件名为 `月度统计_YYYYMMDD_HHMMSS.docx`

### 首次使用（不上传上月Word）
- [ ] 4份周Excel → 生成的Word含标题、6列表头、全名单数据行
- [ ] 总计班次 = 4份周Excel里"实际班次"之和
- [ ] 应值班次 = 4份周Excel里"应值班次"之和
- [ ] 多值/缺班 ≤0 的单元格显示斜线（肉眼在 Word 中验证）
- [ ] 排序：多值最多的在最上；缺班最多的在最下；中间按拼音

### 跨月结转（上传上月Word）
- [ ] 将上一次生成的Word作为"上月" → 数值正确继承：
    - 总计班次 += 上月"多值班次"
    - 应值班次 += 上月"缺班数量"
- [ ] 上月Word里的斜线/空单元格 → 按 0 参与计算（不报错）

### 人员流动
- [ ] 删除总名单中某人后生成 → 该人不出现在Word中，其历史数据被丢弃
- [ ] 新增总名单某人后生成 → 该人出现在Word中，按上月数据=0 计算

### 异常
- [ ] 上月Word表头被破坏 → 弹"上月Word解析失败"，程序不崩溃
- [ ] 外部模板文件不存在时仍可正常生成月统计 Word
- [ ] 输出Word已在Word里打开 → 弹"文件被占用"

## 通用
- [ ] 所有对话框中文显示正常（无乱码）
- [ ] 窗口大小可调整，元素不错位
- [ ] 关闭窗口后进程正常退出（任务管理器确认）
